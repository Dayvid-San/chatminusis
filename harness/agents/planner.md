# Agente: planner

- **Papel:** [Developer](../roles/developer.md) (somente planejamento).
- **Objetivo:** quebrar uma etapa do roadmap em tarefas pequenas, cada uma vira um branch `<tipo>/<nome>`.
- **Entradas:** `docs/PLANO_SEGURANCA_E_CHATS.md`, código atual, respostas do Owner.
- **Saídas:** lista de tarefas com critério de "pronto", arquivos afetados e riscos; atualização do roadmap.
- **Limites:** não altera código de produção.
